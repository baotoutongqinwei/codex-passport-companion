## 功能与边界

| 功能 | 行为 |
| --- | --- |
| 时钟 | 所有页面左上角固定显示 UTC+8、24 小时制 `HH:MM:SS`，每秒更新。从 Mac 的 Unix 时间校准，不受 Mac 显示时区影响。每次开机首次同步前显示 `--:--:--`；同步后断网仍继续走时，原有闲置熄屏行为保持不变。 |
| 额度 | 固定一屏显示 7 天剩余百分比、下一次自动重置时间及最早到期的两次可用重置机会。日期统一 UTC+8、24 小时制。不再显示长期额度和积分余额；未知或详情缺失会明确提示。每 30 秒刷新，额度事件使缓存失效。重置机会只读展示，卡片不会使用它们。 |
| 对话 | 每页三条本地 Codex 对话，按最近真实交互排序，显示运行状态、待处理条数和卡片未读；可切换、翻阅消息、跳到最新回复，不接入 ChatGPT 云端聊天。 |
| 回复 | 卡片每 1.5 秒轮询，历史缓存 5 秒；桥接发起的对话还会接收文字增量事件，长回复分页显示。 |
| 语音 | 长按中键录音、松开结束、预览文字后单击发送。最长 45 秒，16 kHz 单声道 PCM；卡片只保留 8 KB 流式缓冲。默认按中文识别，在本机统一转为简体，预览与发送文字保持一致。 |
| 费用 | 不使用云端转写、API Key、购买或付费兜底。只使用已登录 ChatGPT 账号的可用额度；额度未知或耗尽、其他提供商会阻止发送。原账号订阅条款仍适用。 |
| 对话占用 | 对话正在运行或写入权由其他客户端持有时，把已确认文字加入原对话的 Codex 队列。可继续录音并确认追加到同一队列；配套程序每次运行最多跟踪各对话合计 32 条待处理语音，卡片显示当前对话的待处理条数。入队成功不等于执行，请在桌面 App 确认。 |
| 权限 | 工具权限申请会被拒绝，卡片提示需回电脑处理。桥接不会自动授权，也不会将审批弹窗转发到桌面 App。 |
| 异常 | 录音中断会丢弃；明确拒绝发送或排队时保留可确认草稿。发送或排队超时标记为结果待确认，绝不自动重发。重新录制同一请求前，先在电脑确认。 |
| 中文 | 16 px 点阵字库覆盖 ASCII、U+4E00–U+9FEF 和部分标点；表情、扩展汉字等不支持字符明确替换成 `?`。 |

桥接通过桌面 App 自带的 `codex app-server` 启动独立进程，使用现有账号。
当前安装版本拒绝恢复由桌面占用的对话，返回 `thread already has an active writer`。
明确收到这一拒绝时，桥接改用本机协议的 `thread/queue/add`，不抢写入锁、
不自行启动排队任务，也不改变权限。对话正在运行时也走此排队路径。
每条确认录音有独立的去重标识；已有跟踪消息仍在队列时，后续语音继续追加，
即使对话暂时报告空闲，也不会越过前面的消息直接启动。入队明确被拒绝或达到
跟踪上限会保留草稿；结果未知则不自动重试。只有完整队列读取确认消息已不在
队列，才移除对应跟踪记录；离开队列本身不证明已经执行。跟踪信息保存在内存，
配套程序重启后以桌面队列为准。队列接口取决于 Codex 版本：一次真实 USB 语音、
队列、桌面处理及卡片回复的完整往返已通过；之后四条 USB 语音测试曾同时积压
两条消息，四条消息按序进入桌面对话，该轮多条消息的卡片回复仍待用户确认。
依赖桌面专用动态工具的对话可能仍需电脑操作；审批弹窗不会自动镜像到卡片。

## 在当前工作空间启动

```bash
source ~/aipassport/activate.sh
cd ~/aipassport/codex-companion
python3 bridge/app.py doctor
```

开发用 Mac 已安装离线引擎和模型。新检出项目时，激活工具链后执行
`python3 tools/bootstrap_bridge.py`。脚本下载 MIT 许可的 whisper.cpp v1.8.7，
固定提交 `48f628a84833905ee4a0658ee6d4a5c915ce1997`，校验多语言 base 模型哈希，
并编译 CPU 后端。首次下载需要网络、磁盘空间和 C/C++ 编译器，不需要付费账号或语音 API。

中文转换使用 [opencc-python-reimplemented 0.1.7](https://pypi.org/project/opencc-python-reimplemented/0.1.7/)
（Apache 许可证）的本地 `t2s` 字典。初始化脚本和 `tools/install_transport.sh`
都会安装此固定版本，后者准备启动器使用的虚拟环境。运行主机测试门禁前，
也需在当前 Python 环境安装该组件。转换先于长度和字库检查，确保卡片预览与
确认发送的内容完全一致。组件缺失时语音不可用，不会悄悄退回繁体显示。

```bash
# 首次配置使用 Mac 的局域网 IPv4 地址，建议路由器固定分配。
python3 bridge/app.py setup --host <Mac局域网IP>
python3 bridge/app.py serve
```

保持桥接终端运行；如 macOS 询问，允许局域网访问。
配置后也可以从 Finder 运行 `bridge/start.command`，在菜单选择 Wi-Fi。配对 token、证书、私钥存放在
已忽略的 `.local/` 中，不会嵌入固件或源码包。Mac IP 改变后需要重新生成证书和配置，
并重新配置卡片；新配置验证成功前保留原来的三个配对文件。不要把桥接端口暴露到公网。

明确批准并完成刷机后，在另一个已激活环境的终端执行：

```bash
cd ~/aipassport/codex-companion
python3 bridge/app.py configure --port /dev/cu.usbmodem101
```

串口名称可能变化。命令在本机交互询问 2.4 GHz、WPA2/WPA3 兼容 Wi-Fi 名称和密码，
密码不会回显；将凭据、固定证书、token 和初始时间写入 NVS 并重启卡片。
此命令不刷机，不要把 Wi-Fi 密码发到聊天里。

## 三键操作

| 页面 | 操作 |
| --- | --- |
| 额度 | 中键打开对话列表；长按下键查看连接说明。短按上下键不翻页、不滚动。 |
| 对话列表 | 上下选择，中键打开；长按下翻下一页，长按上返回额度页 |
| 对话内容 | 上下翻消息页，长按下跳到最新；中键打开菜单；长按中键录音 |
| 录音 | 松开中键结束并识别；长按上取消 |
| 识别结果 | 上下滚动；就绪后中键发送；长按上取消 |
| 待机 | 60 秒无操作熄屏；第一次按键只唤醒，不执行操作 |
