# 选择 Codex 卡片模式

全部源码保留在同一项目工作目录中。ESP32-C3 有
8 MB Flash、无 PSRAM，采用四份独立固件控制无线栈和应用状态的内存占用。
刷机前选择版本，卡片不在运行中切换已安装应用。不新增付费 API、云端转写、
中转订阅或自动付费兜底。Codex 仍需要现有账号的可用额度以及 Mac 的互联网连接。

| 固件 | 卡片连接 | Mac 程序 | 功能 |
| --- | --- | --- | --- |
| `wifi` | 与 Mac 同一 2.4 GHz 局域网 | `serve` | 额度、对话、回复、语音、UTC+8 时钟 |
| `usb` | 使用期间保持 USB 数据线连接 | `usb` | 同样的 Codex 功能，不监听网络端口 |
| `ble` | 经过认证的低功耗蓝牙 | `ble` | 同样功能，压缩语音，不监听网络端口 |
| `offline` | 独立运行；USB 可供电、刷机、校时及导出记录 | 校时／导出时运行桌面 0.8.0 | UTC+8 时钟、电量记录、25/5 番茄钟、秒表 |

三种连接版共用固定一屏的额度页：7 天剩余百分比、下一次自动重置时间，以及最早
到期的两次可用重置机会。日期统一 UTC+8、24 小时制；数据缺失会明确提示，卡片
不会使用重置机会。中键打开对话列表，长按下键打开连接说明；0.6.0 起短按下键进入
本机设备信息，中键返回。额度本身仍一屏展示，不滚动。

USB、蓝牙的 Codex 功能仍需本地 Mac 配套程序和保持唤醒的 Mac；离线版校时后可独立运行。
家庭网络或手机热点也可供 Wi-Fi 版使用，前提是热点允许客户端互访。
公司终端和外设策略仍可能限制这些连接；这些版本不会修改 Mac 防火墙、VPN 或公司安全软件。

设备检查点（2026-10-02）：用户批准刷入新版额度页蓝牙固件，三个分段均写后校验
通过，NVS/PHY 保留。首次配对失败，重试后完成认证配对；MTU 247 下实际蓝牙
收发通过，时钟、周额度、重置到期时间和对话列表数据正常。有限启动观察中 ELF
前缀为 `83848bfcb`，空闲堆 55,768 字节、最大连续块 47,104 字节，未观察到崩溃
标记。拔线使用、屏幕/按键、语音吞吐、重启后的绑定持久化和断线行为仍待验收。
合并镜像 SHA-256：`f9b278a35146543061e8151473a3b96a21a0c99eed4f5058ab004b1d50e52503`。

自动息屏后，短按三个功能键中的任意一个，第一次按键只唤醒显示。
独立电源键控制硬件供电，可能中断 USB 或使卡片重启；日常唤醒屏幕请使用功能键。

## 安装与启动

macOS 的 USB/蓝牙用户优先使用[原生桌面应用](codex-desktop.zh_CN.md)，无需开发工具链。
下面命令对应原开发工作空间；新电脑按仓库根目录 README 配置虚拟环境和语音引擎，
不要直接引用只存在于某台电脑上的激活脚本。

```bash
source ~/aipassport/activate.sh
cd ~/aipassport/codex-companion
bash tools/install_transport.sh
bash bridge/start.command
```

启动器可选 Wi-Fi、USB、蓝牙和只读诊断。依赖固定在 `bridge/requirements.txt`，
单独安装到 `.local/transport-venv`。新电脑还需运行一次
`python3 tools/bootstrap_bridge.py` 安装免费本地语音引擎和模型。
使用已有 Codex 登录，不需要 API Key。同一卡片只运行一个连接程序，避免草稿互相干扰。
终端保持打开，Ctrl+C 停止。切换启动器选项不会自动切换固件，刷机须单独确认。

### USB

刷入 USB 版后，用数据线连接，在启动器选 USB。只有一张 ESP32-C3 卡片时自动选择；
多设备时指定串口：

```bash
.local/transport-venv/bin/python bridge/app.py usb --port /dev/cu.usbmodem101
```

串口名称可能变化。先关闭串口监视器和配置程序。无需 Wi-Fi 名称、密码或 TLS 配置。
USB 固件关闭控制台日志，串口由通信协议独占。主机忽略 ROM 启动文字，检查 CRC、长度
和请求编号。断线会放弃未完成录音；发送结果不确定时，先到电脑核实再重新操作。
程序会等待原卡片恢复，并按 USB 序列号自动重连，即使串口名称改变也不会误连其他卡片。
中断的录音会丢弃，待确认草稿和发送去重记录保留，不会自动重发。重新连接时保持程序运行。

### 低功耗蓝牙

刷入蓝牙版，打开 Mac 蓝牙，在启动器选蓝牙。若 macOS 提示，允许终端/Python 的蓝牙权限。
程序仅扫描 CodexCard 自定义服务；多设备时：

```bash
.local/transport-venv/bin/python bridge/app.py ble-scan
.local/transport-venv/bin/python bridge/app.py ble --address <设备标识>
```

macOS 设备标识是 UUID，而不是 MAC 地址。读取受保护特征时会触发系统配对提示，
在 Mac 输入卡片显示的六位码。采用 LE Secure Connections、中间人攻击防护与持久化绑定，
最多保存三台设备。卡片数据只通过经过认证的加密连接发送，配对码出现时会唤醒并保持亮屏。
重置配对：从额度页打开连接说明，**长按中键清除卡片全部蓝牙绑定**，再在 Mac 忽略旧
CodexCard 并重连。仅在 Mac 忽略设备不会清除卡片中的绑定。其他 NVS 设置不受影响。

语音使用独立 IMA ADPCM 数据块，约为原始 PCM 的四分之一；Mac 解码后交给原有本地语音识别。
协商 MTU 低于 128 时不能录音，但文字与额度仍可使用。断线或音频传输过慢会终止录音，
不会自动发送或切换到付费服务。后续已通过此前程序下的 45 秒蓝牙录音及原生应用下
一次卡片断电重连；持续无线干扰、距离、新电脑首次配对和不同环境的麦克风质量仍待验证。
蓝牙客户端行为遵循 [Bleak 的 macOS 文档](https://bleak.readthedocs.io/en/stable/backends/macos.html)。

## 所有版本的电量记录（固件 0.10.0）

四种固件共用 192 条 NVS 环形记录和出厂 MAC 标识。开机时记录电量百分比和电压，拔线、
断开 Mac、自动息屏后继续；通常每五分钟一次，低电量和突然下降时更密集。已保存记录在
完全断电后保留，保留 NVS 且分区兼容地切换固件也保留。所有版本设备页均显示记录条数或
存储失败。0.10.1 在录音准备、采集、收尾和发送期间暂缓采样／写入和补传，草稿确认与 Mac 转写期间继续，旧缓存值不会标成新的采样时间。

| 版本 | 导入方式 |
| --- | --- |
| 蓝牙 | 通过已认证的正常蓝牙连接补传，无需 USB 供电 |
| USB | 通过正常 CPv1 USB 连接补传；拔线期间样本留在卡片 |
| Wi-Fi | 使用已配置、认证的 TLS 服务；设置共享 `PASSPORT_DATA_DIR` 后可在桌面图表查看 |
| 离线 | 沿用桌面运行期间的 USB 自动导入 |

USB／蓝牙及 TLS 共用 `POST /v1/battery`，字段为 `card_serial`、`log_id`、`storage_ok`，
以及最多 16 行的 `samples`。每行为
`[sequence, utc_seconds_or_zero, uptime_seconds, percent_or_minus_one, millivolts_or_minus_one]`。
Mac 成功持久化后才返回 `ok`、匹配的 `log_id`、末条序号 `ack`（空页为 0），
并返回 `now` 独立校时，不依赖 Codex 状态成功。失败不推进游标，重连从最早保留样本补传，
Mac 按卡片／日志／序号去重。采样本身不需要连接，时钟未知时保留开机秒数，不猜测绝对时间。
充电电流／状态仍不可读。新接口需要桌面 0.9.0，旧离线 USB 导入保持兼容。

## 完全离线版操作

| 页面或操作 | 按键 |
| --- | --- |
| 切换工具 | 上下循环切换时钟、番茄钟、秒表、设备信息；计时不会因换页停止 |
| 设备信息 | 本机电量、温度、堆／程序占用、Flash、固件、运行时长及电量记录条数；中键返回时钟 |
| 校准时钟 | 新版离线固件连接运行中的 Mac 桌面 0.8.0 时自动校时；也可用中键依次进入小时、分钟、保存，上下调整，长按上取消 |
| 番茄钟 | 中键开始或暂停；阶段完成后，中键启动下一段 5 分钟休息或 25 分钟专注 |
| 重置番茄钟 | 长按中键重置本次计时及完成轮数 |
| 秒表 | 中键开始、暂停或继续；长按中键清零 |
| 熄屏与唤醒 | 60 秒无操作熄屏，第一次按键只唤醒；番茄钟阶段完成会亮屏 |

所有页面左上角显示 UTC+8、24 小时制秒钟。桌面 0.8.0 在离线 0.9.0 固件烧录成功后尝试校时；
运行期间检测 USB 连接／重连后也自动校时，无需 Codex 登录、语音模型或网络。桌面程序没运行时，
USB 线本身不会传时间，可继续手动输入当前 UTC+8 时间，保存时秒数从零开始。
熄屏仍走时。不假定硬件具有独立电池供电的 RTC；断电或重启后时钟与计时状态重置，
`--:--:--` 表示需要校时。番茄钟完成是屏幕提示，等待确认后才开始下一阶段。
离线版不提供 Codex、语音识别、对话或额度。

### 拔线电量记录（离线固件 0.9.0）

卡片开机后由本机每 5 分钟记录 CW2017 的剩余百分比和电压；电量 ≤10% 时每分钟记录，
30 秒内发现下降 ≥3 个百分点也会补记。记录在 NVS 环形缓冲区，最多 192 条；
常规间隔约覆盖最近 16 小时，低电量密集采样会缩短覆盖时长。熄屏及拔掉 USB 后继续记录，
完全断电后已成功写入的记录仍保留。若设备页显示“电量记录保存失败”，本次采样可能未写入。

重新连接 USB、运行桌面 0.8.0 后，应用会导入、去重并保存到 Mac 私有数据目录的
`battery-history.csv`，设备信息页可打开。每条有百分比、电压、本次开机时长；
只有此前从 Mac 校过时，才有可靠的 UTC／UTC+8 绝对时间。此设备没有已确认的充电状态／电流接口，
日志不把“连着 Mac”当成“正在充电”；判断拔线时段请结合实际拔插时间。百分比来自电量计，
其跳变与电压趋势需一起看，不能直接当作电池容量测试。

## 编译、验证和协议

```bash
bash tools/build_variants.sh
bash tools/preview_companion.sh
# 单独重编某个版本：
bash tools/validate.sh --all --profile usb
```

各合并镜像位于 `build/variants/<版本>/FoloToy-AI-Passport-full.bin`，刷写起始地址 `0x0`，
同目录保留内存报告。镜像 SHA-256 对应 `build/firmware/<sha256>/` 中经过验证的 ELF/MAP。
为兼容旧流程，顶层合并镜像始终是 Wi-Fi 版，选择其他版本时务必使用对应路径。
合并刷写可能重置配置，须遵守[数据策略](development/engineering/firmware-layout.zh_CN.md)并获得确认。

门禁检查最终 ELF 中只有所选版本的无线初始化函数。`CONFIG_ESP_WIFI_ENABLED` 是芯片能力
标志，不能据此判断 Wi-Fi 是否运行或被移除。链接器剩余内存不等于运行时空闲堆，无线、音频、
任务分配仍需上板测量。所有版本复用相同中文字库和 BSP。

CPv1 帧包含 16 字节头（`CPv1`、u32 编号、u16 状态、u16 UTF-8 路径长度、u32 正文长度）、
路径、正文和 IEEE CRC32，整数为小端。状态零为请求，响应使用 200–599 且路径为空。
路径最长 1536 字节，正文最长 8192，请求正文最长 4096。卡片顺序发请求，响应超时 30 秒，
丢弃过期编号。协议本身不提供认证：USB 信任物理连接的电脑，蓝牙另行认证对端。
ADPCM 正文为 u16 样本数、i16 预测值、u8 步长索引、零保留字节，然后每样本四位编码，
低半字节优先，包含第零样本；最多 2048 个样本。各块独立解码，写入音频前校验。

主机测试覆盖实际 C/Python 编解码互通、损坏和超限数据、分片 PTY 往返、模拟认证蓝牙、
重复发送保护、本地压缩中文转写、离线计时及真实 LVGL/字库渲染。这些不等同于硬件验收。
新固件须在获得确认后上板测试，包括 45 秒语音、断线、低电量、按键释放、中文排版、
绑定持久化、时钟同步和桌面对话发送/回复。通用功能见[随行卡片指南](codex-companion.zh_CN.md)。
