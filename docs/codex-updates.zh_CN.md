# Codex 助手更新记录

本记录按应用的已完成开发批次追加。批次完成不表示已发布 GitHub Release，也不表示
完整真机验收；下载区产物可能落后于这里记录的源码。更早的工作见
[应用说明](codex-companion.zh_CN.md)和仓库历史。

## 每批记录约定

- 每完成一批更新，在交付或提交前向下追加一条记录；编号接续当前最大值，不重用编号。
- 日期按 UTC+8 记录完成日；有实际应用版本时注明版本，纯文档更新不人为升级版本号。
- 记录用户可见变化、Mac 更新或卡片烧录要求；分别写明构建、主机测试、真机测试、未验证项，
  区分本次结果和沿用的历史结果。
- 中英文记录同步维护；更新 README 的最新批次入口，界面变化时刷新对应截图。
- 卡片预览使用可公开的示例数据，明确标注 LVGL 渲染，不冒充实拍。
  私有配置、录音、个人对话和发布二进制包不进入 Git。
